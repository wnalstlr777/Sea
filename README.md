# OCEAN CRUISE v0.1

Three.js + Vite 기반 바다·곡면 지평선·항해감 웹 프로토타입입니다. 서버, 계정, 멀티플레이, 날씨 기능은 포함하지 않습니다. 단층 선체와 알약 캐릭터의 갑판 이동을 지원합니다.

## 실행

Node.js 20.19+ 또는 22.12+가 필요합니다. 이 환경에서는 Node.js 24로 검증했습니다.

```sh
npm ci
npm run dev
```

브라우저에서 개발 서버가 표시하는 주소를 엽니다. 배포 파일은 `npm run build`로 생성하며, `npm run preview`로 확인할 수 있습니다.

## 사용

- WASD / 방향키: 카메라 기준 갑판 이동 (초당 3.5m)
- 모바일: 왼쪽 하단 조이스틱 이동, 나머지 화면 드래그로 둘러보기
- 드래그 / 한 손가락: 캐릭터 중심 360도 회전
- 휠 / 두 손가락 핀치: 줌
- 우측 패널: 곡률, 파도 높이, 자연 파도 속도, 항해 속도, 항적 강도, 네 가지 HEX 색상 변경
- 모바일에서는 오른쪽 상단 ☰ 메뉴로 설정을 열고 ×로 닫습니다. PC에서는 기존 접이식 패널을 유지합니다.
- 기본 카메라는 알약 캐릭터 뒤에서 선수 방향을 바라보며 이동을 따라갑니다. 드래그로 주변을 둘러보고 줌으로 배 전체를 볼 수 있습니다.
- 패널 제목을 눌러 접거나 펼치고, 초기화 버튼으로 기본값 복원
- 뾰족한 쪽이 선수(-Z), 넓고 평평한 쪽이 선미(+Z)입니다.

배는 원점에 고정된 약 80m × 24m × 6m 단층 크루즈 선체입니다. `src/ship.js`의 `SHIP`과 `DECK`가 크기와 윤곽을 정의합니다. 같은 윤곽을 갑판·난간·충돌 경계에 사용하며 캐릭터 반지름을 포함한 안쪽 경계로 이동을 제한합니다. 캐릭터는 갑판 높이에 고정되고 선체 밖으로 떨어지지 않습니다.

## 구현

`src/ocean.js`는 배 주변에 정점을 집중한 방사형 메시와 커스텀 GLSL 셰이더를 사용합니다. XZ 반경의 제곱에 비례해 높이를 낮추는 구면 캡 근사로 모든 수평 방향에 같은 곡률을 적용합니다. 실제 지구 규모나 정확한 구체 시뮬레이션은 아닙니다. 원경 파도 단순화와 대기색 혼합으로 메시 경계를 숨깁니다.

자연 파도 시간과 항해 이동량을 독립적으로 누적합니다. 항해 속도 0에서는 이동량이 고정되고 항적은 사라지며 자연 파도는 계속됩니다. 파도 속도 0에서는 자연 파도만 멈춥니다. 항적은 카메라와 관계없이 선미 +Z 방향에 고정됩니다. 하늘과 지평선은 스크롤되지 않습니다.

## 최소 검수 및 성능

- `npm run build`: 프로덕션 빌드
- `npm test`: 전체 선체 윤곽·모서리의 캡슐 충돌 경계 및 지속 이동 검사
- 화면 우측 하단: 실시간 FPS, Draw Calls, Triangles. 기기와 화면 배율에 따라 FPS가 달라집니다.
- 브라우저 개발자 도구 Performance로 프레임 시간을 확인할 수 있습니다. `window.oceanCruise.renderer.info.render`에서도 호출·삼각형 수를 확인할 수 있습니다.
- 회전하며 사방 지평선 확인, 곡률 0~4 비교, 네 색상 변경, 항해 속도 0에서 흐름 정지/자연 파도 유지, 모바일 크기에서 회전·줌·패널 확인을 권장합니다.
- 이 작업에서는 Chromium WebGL(소프트웨어 렌더링)으로 렌더링·콘솔 오류·패널 변경·4방향 카메라·속도 0의 시간 분리·모바일 뷰포트를 확인했습니다. 실제 모바일 기기와 하드웨어 GPU 성능은 별도 검수 대상입니다.

## GitHub Pages 배포

`main` 변경 시 GitHub Actions가 빌드 결과를 `gh-pages` 브랜치에 갱신합니다.
저장소 Settings → Pages에서 배포 소스를 **Deploy from a branch**, 브랜치를 **gh-pages / (root)**로 지정합니다.
프로젝트 주소는 `https://wnalstlr777.github.io/Sea/`입니다. Pages가 활성화되고 배포가 완료된 후 접속할 수 있습니다.

## 낮과 밤

기본 시간은 석양(18:00)입니다. 설정 메뉴의 SKY에서 낮(12시)·석양(18시)·밤(0시) 프리셋 또는 0~24시 슬라이더로 즉시 변경합니다. 시간은 자동으로 흐르지 않습니다. 자연 파도 속도나 항해 속도와 독립적입니다.
태양은 선수(-Z) 방향에 위치하고 시간에 따라 높이·색·밝기가 달라집니다. 하늘, 환경광, 선체 조명, 바다 명도와 태양 반사도 함께 변합니다. 밤에는 달이 떠오르고 푸른 달빛과 수면 반사가 나타납니다. 약한 환경광으로 갑판 이동이 가능합니다. 바다의 네 색상 설정은 그대로 유지하며 시간대 조명과 혼합합니다.

선체 길이와 폭을 이전 버전의 각각 두 배로 확장했습니다. 갑판 높이 6.8m, 난간 높이 1.05m, 캐릭터 크기와 이동 속도는 유지합니다. 선체 윤곽과 충돌 경계·항적 위치도 확대된 크기에 맞췄습니다.

태양과 달은 수평 이동을 포함한 기울어진 연출용 궤도를 사용합니다(실제 천문 시뮬레이션은 아님). 시간 프리셋·슬라이더 변경은 부드럽게 보간되며, 지평선의 대기 그라데이션으로 하늘과 원경 수면을 연결합니다.

### 모바일 메뉴·야간 재질·수면 품질

모바일 설정 메뉴는 화면 높이의 최대 50%와 폭 240px로 제한하며 내부를 스크롤합니다. PC 패널은 기존 배치를 유지합니다. 야간에는 높은 각도의 푸른 달빛 DirectionalLight와 약한 보조광이 갑판·선체·캐릭터를 비춥니다. 난간은 발광 없는 MeshStandardMaterial의 인스턴스 파이프로 구성해 낮밤 조명에 반응합니다. 수면은 화면상의 파장 크기에 따라 잔물결을 필터링하고 반사 하이라이트를 완화하여 원거리 격자·반짝임을 줄였습니다.
