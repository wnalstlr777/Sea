# OCEAN CRUISE v0.1

Three.js + Vite 기반 바다·곡면 지평선·항해감 웹 프로토타입입니다. 서버, 계정, 멀티플레이, 캐릭터, 날씨 기능은 포함하지 않습니다.

## 실행

Node.js 20.19+ 또는 22.12+가 필요합니다. 이 환경에서는 Node.js 24로 검증했습니다.

```sh
npm ci
npm run dev
```

브라우저에서 개발 서버가 표시하는 주소를 엽니다. 배포 파일은 `npm run build`로 생성하며, `npm run preview`로 확인할 수 있습니다.

## 사용

- 드래그 / 한 손가락: 배 중심 360도 회전
- 휠 / 두 손가락 핀치: 줌
- 우측 패널: 곡률, 파도 높이, 자연 파도 속도, 항해 속도, 항적 강도, 네 가지 HEX 색상 변경
- 모바일에서는 오른쪽 상단 ☰ 메뉴로 설정을 열고 ×로 닫습니다. PC에서는 기존 접이식 패널을 유지합니다.
- 기본 카메라는 갑판 위 눈높이에서 선수 방향 지평선을 바라봅니다. 드래그로 주변을 둘러보고 줌으로 배 바깥까지 물러날 수 있습니다.
- 패널 제목을 눌러 접거나 펼치고, 초기화 버튼으로 기본값 복원
- 청록색 화살표가 선수(-Z), 주황색 선이 선미(+Z)입니다.

배는 원점에 고정된 40m × 12m × 6m 박스입니다. 크기는 `src/main.js`의 `SHIP` 상수에서 변경합니다. 카메라의 줌·수직 회전 제한으로 수면 아래 진입을 막습니다.

## 구현

`src/ocean.js`는 배 주변에 정점을 집중한 방사형 메시와 커스텀 GLSL 셰이더를 사용합니다. XZ 반경의 제곱에 비례해 높이를 낮추는 구면 캡 근사로 모든 수평 방향에 같은 곡률을 적용합니다. 실제 지구 규모나 정확한 구체 시뮬레이션은 아닙니다. 원경 파도 단순화와 대기색 혼합으로 메시 경계를 숨깁니다.

자연 파도 시간과 항해 이동량을 독립적으로 누적합니다. 항해 속도 0에서는 이동량이 고정되고 항적은 사라지며 자연 파도는 계속됩니다. 파도 속도 0에서는 자연 파도만 멈춥니다. 항적은 카메라와 관계없이 선미 +Z 방향에 고정됩니다. 하늘과 지평선은 스크롤되지 않습니다.

## 최소 검수 및 성능

- `npm run build`: 프로덕션 빌드
- 화면 우측 하단: 실시간 FPS, Draw Calls, Triangles. 기기와 화면 배율에 따라 FPS가 달라집니다.
- 브라우저 개발자 도구 Performance로 프레임 시간을 확인할 수 있습니다. `window.oceanCruise.renderer.info.render`에서도 호출·삼각형 수를 확인할 수 있습니다.
- 회전하며 사방 지평선 확인, 곡률 0~4 비교, 네 색상 변경, 항해 속도 0에서 흐름 정지/자연 파도 유지, 모바일 크기에서 회전·줌·패널 확인을 권장합니다.
- 이 작업에서는 Chromium WebGL(소프트웨어 렌더링)으로 렌더링·콘솔 오류·패널 변경·4방향 카메라·속도 0의 시간 분리·모바일 뷰포트를 확인했습니다. 실제 모바일 기기와 하드웨어 GPU 성능은 별도 검수 대상입니다.
